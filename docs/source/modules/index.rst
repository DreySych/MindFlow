Структура проекта
-----------------

MindFlow организован как Django проект с несколькими приложениями:

* **ai** — интеллектуальный поиск с использованием LLM
* **questions** — система вопросов, комментариев и ответов
* **users** — управление пользователями и подписками
* **complains** — система жалоб и модерации
* **notifications** — уведомления пользователей
* **main** — главная страница и общие утилиты

Каждое приложение следует стандартной структуре Django:

.. code-block:: text

   app_name/
   ├── models.py       # Модели базы данных
   ├── views.py        # View-функции
   ├── forms.py        # Формы Django
   ├── urls.py         # URL маршруты
   ├── admin.py        # Админ-панель
   ├── apps.py         # Конфигурация приложения
   └── tests.py        # Тесты
