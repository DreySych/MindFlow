Модуль complains (Жалобы)
=========================

Система жалоб и модерации контента.

Обзор
-----

Модуль ``complains`` обеспечивает:

* Создание жалоб на контент и пользователей
* Панели модерации для администраторов
* Обработку жалоб (принятие/отклонение)
* Уведомления администраторов о новых жалобах
