Развёртывание
=============

Локальное развёртывание
------------------------

Для локальной разработки используется встроенный сервер Django:

.. code-block:: bash

   python manage.py runserver

Production-подготовка
---------------------

Перед развёртыванием необходимо:

* задать ``DEBUG=False``;
* задать безопасный ``SECRET_KEY``;
* настроить ``ALLOWED_HOSTS``;
* выполнить миграции;
* собрать static-файлы;
* настроить переменные окружения;
* убедиться, что ``.env`` и ``db.sqlite3`` не попадают в репозиторий;
* проверить работу WebSocket-соединений.

Миграции
--------

.. code-block:: bash

   python manage.py migrate

Сбор статических файлов
-----------------------

.. code-block:: bash

   python manage.py collectstatic

ASGI
----

Проект использует ASGI, потому что в нём есть WebSocket-функционал для личных сообщений и обновления данных в реальном времени.

Точка входа:

.. code-block:: text

   The_Final_Build/asgi.py

Логи
----

Логи пишутся в папку:

.. code-block:: text

   logs/project.log

В логах фиксируются важные действия пользователей, поиск, создание и редактирование постов, удаление, обращения к тегам и ошибки AI-подбора.

Рекомендации для сервера
------------------------

Для полноценного production-развёртывания рекомендуется использовать:

* Daphne или Uvicorn для ASGI;
* Nginx как reverse proxy;
* отдельное хранилище для media-файлов;
* PostgreSQL вместо SQLite;
* переменные окружения для всех секретов;
* systemd или Docker для воспроизводимого запуска.
