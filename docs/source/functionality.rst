Функциональность
================

Посты
-----

Пользователь может создавать, редактировать и удалять свои посты. Пост содержит заголовок, необязательное описание, изображения, рейтинг, embedding для поиска и один обязательный тег.

При создании поста:

* проверяется авторизация и статус пользователя;
* валидируется форма;
* сохраняются изображения только допустимых типов;
* ограничивается количество изображений;
* создаётся embedding для semantic search;
* сохраняется выбранный тег.

Теги
----

У каждого поста один тег. Список тегов хранится в ``questions/available_tags.txt`` и используется в форме создания/редактирования поста.

Поддерживается:

* обязательный выбор тега;
* пункт ``Другое`` для общего режима;
* фильтрация главной страницы по выбранному тегу;
* отображение тега в карточке и на странице поста;
* переход на главную страницу с фильтром при клике по тегу;
* AI-подбор тега по заголовку и описанию.

Поиск
-----

В проекте есть два вида поиска:

* semantic search на главной странице;
* AI-поиск на отдельной странице.

Semantic search использует эмбеддинги постов и сравнивает их с эмбеддингом пользовательского запроса. Это позволяет находить близкие по смыслу посты, а не только точные совпадения слов.

AI-поиск формирует ответ на основе постов, комментариев и ответов, которые попали в контекст.

Комментарии и ответы
--------------------

К постам можно оставлять комментарии. На комментарии можно отвечать. При ответе автор комментария получает уведомление.

Лайки и дизлайки
----------------

Рейтинг поддерживается для:

* постов;
* комментариев;
* ответов.

Повторное нажатие снимает голос. Переключение с лайка на дизлайк и наоборот корректно пересчитывает рейтинг.

Подписки
--------

Пользователь может подписаться на другого пользователя и отписаться от него. Подписки используются в ленте рекомендаций и в профиле.

Уведомления
-----------

Уведомления создаются при важных действиях:

* комментарий к посту;
* ответ на комментарий;
* лайк поста;
* подписка;
* жалоба для модераторов.

Жалобы и модерация
------------------

Пользователь может отправить жалобу на пост, комментарий, ответ или пользователя. Модератор через панель жалоб может принять или отклонить жалобу.

При принятии жалобы может быть:

* удалён пост;
* удалён комментарий;
* удалён ответ;
* заблокирован пользователь.

Личные сообщения
----------------

Личные сообщения работают через WebSocket. История сообщений загружается частями, чтобы не открывать весь диалог сразу.

Lazy loading
------------

На главной странице посты подгружаются частями. В чате старые сообщения также подгружаются постепенно. Это уменьшает нагрузку и ускоряет открытие страниц.
