Быстрый старт
=============

Минимальный сценарий проверки проекта
-------------------------------------

1. Запустить сервер разработки.
2. Зарегистрировать пользователя.
3. Создать пост с заголовком, описанием и тегом.
4. Проверить отображение поста на главной странице.
5. Нажать на тег поста и проверить фильтрацию.
6. Создать комментарий и ответ.
7. Поставить лайк/дизлайк посту, комментарию и ответу.
8. Подписаться на другого пользователя.
9. Проверить уведомления.
10. Отправить жалобу и обработать её через панель модерации.
11. Проверить AI-поиск и AI-подбор тега.
12. Проверить личные сообщения.

Запуск тестов
-------------

.. code-block:: bash

   python manage.py test

Генерация документации
----------------------

Из корня проекта:

.. code-block:: bash

   sphinx-build -b html docs/source docs/build/html

Или из папки ``docs``:

.. code-block:: bash

   make html

Готовая HTML-документация появится в папке:

.. code-block:: text

   docs/build/html/
