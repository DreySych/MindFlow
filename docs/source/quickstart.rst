Быстрый старт
=============

Это руководство поможет вам быстро начать работу с The Final Build.

Создание первого вопроса
------------------------

1. Войдите в систему или зарегистрируйтесь
2. Нажмите кнопку **"Создать вопрос"**
3. Заполните форму:

   * **Заголовок:** краткое описание вопроса
   * **Описание:** подробная информация
   * **Теги:** (опционально) для категоризации

4. Нажмите **"Опубликовать"**

Комментирование
---------------

Чтобы добавить комментарий к вопросу:

1. Откройте страницу вопроса
2. Прокрутите до формы комментариев
3. Введите текст комментария
4. Нажмите **"Отправить"**

Ответы на комментарии
~~~~~~~~~~~~~~~~~~~~~

Для ответа на комментарий:

1. Нажмите **"Ответить"** под комментарием
2. Введите ответ
3. Нажмите **"Отправить"**

Использование AI-поиска
-----------------------

AI-поиск позволяет находить информацию в вопросах с помощью LLM:

1. Перейдите на страницу **AI-поиска**: ``/ai/``
2. Введите запрос, например: *"как работает Django ORM"*
3. Нажмите **"Поиск"**
4. Получите интеллектуальный ответ на основе контента

Примеры запросов
~~~~~~~~~~~~~~~~

* "расскажи про все вопросы о Python"
* "что спрашивали про Django"
* "найди информацию о тестировании"

.. note::
   Если в запросе есть слово "все", будут проанализированы все вопросы.
   Иначе - только последние 30.

Лайки и дизлайки
----------------

Вы можете голосовать за вопросы:

* 👍 **Лайк** — если вопрос полезный
* 👎 **Дизлайк** — если вопрос некачественный

.. warning::
   Нельзя лайкнуть свой собственный вопрос.

Подписки
--------

Чтобы подписаться на пользователя:

1. Откройте профиль пользователя
2. Нажмите кнопку **"Подписаться"**
3. Вы будете получать уведомления о его активности

Уведомления
-----------

Вы получаете уведомления когда:

* Кто-то комментирует ваш вопрос
* Кто-то отвечает на ваш комментарий
* Кто-то лайкает ваш вопрос
* Кто-то подписывается на вас

Просмотр уведомлений:

1. Нажмите на иконку 🔔 в навигации
2. Перейдите на страницу ``/notifications/``

.. note::
   Уведомления автоматически помечаются как прочитанные.

Жалобы на контент
-----------------

Если вы обнаружили нарушение:

1. Нажмите кнопку **"Пожаловаться"** на объекте
2. Опишите причину (макс. 500 символов)
3. Отправьте жалобу

Администраторы рассмотрят жалобу и примут решение.

.. warning::
   Нельзя жаловаться на свой собственный контент.

Редактирование профиля
----------------------

Для редактирования профиля:

1. Перейдите в **"Настройки профиля"**
2. Загрузите аватар
3. Обновите информацию о себе
4. Сохраните изменения

Модерация (для администраторов)
--------------------------------

Если у вас роль администратора (``is_staff=True``):

1. Перейдите в панель жалоб:

   * ``/complaint/panel/questions/`` — жалобы на посты
   * ``/complaint/panel/users/`` — жалобы на пользователей
   * ``/complaint/panel/comments/`` — жалобы на комментарии

2. Рассмотрите жалобу
3. Примите решение:

   * **Принять** — удалить контент или заблокировать пользователя
   * **Отклонить** — оставить без изменений

API для разработчиков
---------------------

Для программного доступа см. :doc:`api`.

Пример использования AI-поиска через API:

.. code-block:: javascript

   fetch('/ai/api/', {
       method: 'POST',
       headers: {'Content-Type': 'application/json'},
       body: JSON.stringify({q: 'ваш запрос'})
   })
   .then(r => r.json())
   .then(data => console.log(data.answer));
