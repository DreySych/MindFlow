Документация MindFlow
=====================

**MindFlow** — веб-платформа для обмена знаниями. Пользователи создают посты, выбирают теги, обсуждают материалы в комментариях и ответах, подписываются друг на друга, получают уведомления, отправляют жалобы и используют AI-поиск по содержимому платформы.

Документация описывает архитектуру проекта, основные модули, API-эндпоинты, запуск, тестирование, безопасность, паттерны проектирования и автодокументацию кода.

Основной функционал
-------------------

* регистрация, вход, выход и восстановление пароля;
* профили пользователей и настройки аккаунта;
* создание, редактирование и удаление постов;
* обязательный выбор одного тега для поста;
* AI-подбор тега по заголовку и описанию;
* фильтрация главной страницы по тегам;
* semantic search по постам через эмбеддинги;
* AI-поиск по постам, комментариям и ответам;
* комментарии и ответы;
* лайки и дизлайки постов, комментариев и ответов;
* подписки на пользователей;
* уведомления;
* личные сообщения через WebSocket;
* жалобы и панель модерации;
* lazy loading для ленты и сообщений.
